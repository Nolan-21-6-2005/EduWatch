# Thư mục `logs/`

Nơi lưu nhật ký và ghi chú của project (không phải log chạy ứng dụng).

| File | Nội dung |
|---|---|
| `CHANGELOG.md` | Nhật ký thay đổi chính thức, mới nhất ở trên cùng. **Thêm mục mới vào file này.** |
| `archive/` | Các ghi chú gốc trước khi gom, giữ nguyên nội dung để đối chiếu. Có thể đã lỗi thời. |

Tệp `*.log` (nếu sau này có ghi log chạy) đã được `.gitignore` loại trừ.
